# 🚀 DevConf 2026

A responsive developer conference landing page built as a Programming Hero assignment. 
The website presents DevConf 2026 with a modern conference layout, speaker information,
pricing plans, event highlights, and a responsive design.


## ✨ Features

- Responsive and modern conference landing page
- Navigation bar with conference sections
- Hero/banner section with registration CTA
- Speaker showcase with speaker profiles
- Multiple conference pricing plans
- "Why Attend DEVCONF 2026" feature section
- Social media links in the footer
- Mobile, tablet, and desktop responsive layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts (Poppins)

## 📦 Dependencies

This project does not require any package manager or external npm dependencies.

External resource used:
